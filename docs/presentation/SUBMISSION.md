## Краткое описание (если в форме есть такое поле)

AulSabaq AI помогает учителю малокомплектной школы, который ведёт урок сразу для 2–4 классов. Учитель вводит
классы и темы, через 2–3 минуты получает совмещённый урок на 45 минут: поминутный план (в каждую минуту учитель
только с одним классом, это считает код), объяснение темы со слайдами для каждого класса и карточки на всё время
самостоятельной работы. Ученики входят по коду с телефона, получают подсказки без готового ответа и могут позвать
учителя; учитель видит на панели, кто застрял. Работает на казахском и русском, без регистрации.

## Проверочный пример

Без вызова ИИ, около 5 минут: главная → «Открыть демо-урок» → «Показать на экране» у 4 класса (12 слайдов) →
«Получить код для учеников» → на телефоне или во второй вкладке `aulsabaq-ai.vercel.app/join`, код, «4 класс»,
имя «Даша» → карточка 1: ответ `1, 2, 3` даёт «Пока не так», две подсказки, «Мне нужна помощь учителя» →
карточка 7 («Раздели столбиком: 864 : 4»): ответ `216` даёт «Верно!» → на вкладке урока в панели «Ученики на уроке»
видно Дашу, флаг помощи и «Где было трудно».

С ИИ: «Создать урок» → Математика, 2 класс «Сложение двузначных чисел с переходом через десяток», 4 класс
«Деление на однозначное число» → «Собрать урок». Ход сборки виден на экране, урок готов за 1,5–3 минуты.

## Видео до 1 минуты

Готовое видео: `docs/presentation/video/AulSabaq-AI-sound.mp4` (1920×1080, 60 секунд, кадры сняты с рабочего сайта).
Звук из ElevenLabs: голос за кадром (голос «AulSabaq: рекламный», создан для ролика), 8 эффектов и музыка; что и когда
звучит, описано в `video/sound.json`, сведение `video/audio.mjs`. Без звука: `video/AulSabaq-AI.mp4`. Если форма просит ссылку на YouTube, загрузите файл как «доступ по ссылке».
Исходник анимации `video/video.html`, рендер `video/render.mjs`.

Если захотите записать своё видео с голосом, ниже сценарий: компьютер (учитель) и телефон (ученик) рядом.

| Секунды | На экране | Голос |
|---|---|---|
| 0–8 | Главная, партитура урока | «В Казахстане 2 654 малокомплектные школы. Один учитель ведёт урок сразу для нескольких классов.» |
| 8–20 | «Создать урок»: 2 и 4 класс, темы, «Собрать урок», анимация сборки | «Учитель вводит классы и темы, и через пару минут получает совмещённый урок на 45 минут.» |
| 20–30 | «Ход урока»: графит и мята | «В каждую минуту учитель только с одним классом. Расписание считает код, а не ИИ.» |
| 30–40 | «Показать на экране»: пример 756 : 3 по шагам | «Для каждого класса объяснение темы со слайдами: правило, схема, примеры по шагам.» |
| 40–52 | Телефон: вход по коду, неверный ответ, подсказка, «Мне нужна помощь» | «Пока учитель с другим классом, ученики решают карточки с телефона. Подсказка наводит, но не даёт ответ.» |
| 52–60 | Панель учителя: «Даша, карточка 7» | «А учитель видит, кто застрял. AulSabaq AI: aulsabaq-ai.vercel.app.» |
