малокомплектные школы в Казахстане, каждая вторая сельская. Один учитель ведёт урок сразу для нескольких классов: пока объясняет одному, остальные ждут без заданий своего уровня и без помощи.

  1. Поминутный план. В каждую минуту учитель только с одним классом: расписание считает код, а не ИИ.
  2. Объяснение темы со слайдами для каждого класса: правило, схема, примеры по шагам, «Найди ошибку».
  3. Карточки на всё время без учителя, запас для быстрых и тренажёр без конца.
  4. Ученики входят по коду с телефона: подсказки без готового ответа, кнопка «Мне нужна помощь», учитель видит, кто застрял.
Настоящий урок: 2 и 4 класс, 45 минут
