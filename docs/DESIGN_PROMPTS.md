# Промпты для генерации дизайна AulSabaq AI — стиль «Ризограф»

Каждый промпт готов целиком: стиль и запреты уже внутри. Копируй блок от начала до конца.

## Порядок
1. Сгенерируй **промпт 0** (первый экран). Если результат нравится — это твой эталон.
2. Для всех следующих экранов **прикрепляй картинку из промпта 0** как референс. Первая строка каждого промпта уже просит модель повторить её стиль. Без картинки эта строка просто игнорируется — ничего не сломается, но экраны будут похожи хуже.
3. Ошибки в кириллице — нормально, тексты я возьму из кода. Если надписи совсем каша, перегенерируй.
4. Пришли мне картинки и по фразе на экран: что нравится, что нет.

Инструмент: ChatGPT (генерация картинок) или Gemini (Nano Banana).
