## Что показал опыт с одним промптом

24 ноября выполнены 10 пар запросов: пять ru и пять kk, разные предметы, два или три класса.
Основная модель обеих сторон OpenAI `gpt-6-luna` из локальной конфигурации. Один промпт получил
JSON-схему; продукт использовал обычный многошаговый конвейер. Одинаковую автоматическую проверку
расписания и карточек прошли 0/10 и 7/10 соответственно. У продукта два отказа `invalid_plan`
и один возвращённый урок с мягким замечанием TIME: карточек практики на 14 из требуемых 23 минут.
Медианное время всех попыток 31,0 с и 134,2 с; продукт дополнительно строил объяснения.

Это локальный технический опыт, не апробация у учителей и не доказательство, что одним промптом
невозможно получить хороший план. Педагогическое качество, стоимость и время подготовки учителя
не измерялись; фактическая быстрая модель вспомогательных запросов не записана. Преимущество
приложения связано также с рассчитанным расписанием и работой с состоянием учеников: вход по коду,
ответы, запросы помощи, панель. Текстовый ответ сам по себе эту работу не выполняет.
[Таблица и исходные результаты](TEST_LOG.md#проверка-12-24-ноября-t8-один-промпт-против-aulsabaq),
[метод и ограничения](../benchmarks/README.md).

## Паспорт проекта

**Название проекта и автор.** AulSabaq AI. Автор: Асанали Аскаров, Tech Orda (Data Science Academy).

**Направление.** Школа.

**Проблема и пользователь.**
Пользователь: учитель малокомплектной (сельской) школы Казахстана, который ведёт урок одновременно для двух
или трёх классов в одном кабинете. Таких школ 2 654, это 51% сельских школ.
Проблема: пока учитель объясняет одному классу, остальные должны работать сами. Учителю приходится каждый раз
вручную составлять поминутный план и задания своего уровня для каждого класса; без этого самостоятельная работа
превращается в ожидание. Разрыв результатов город–село по чтению в PISA 2022 составляет 37 баллов.
Источники цифр: [Азаттык Рухы](https://rus.azattyq-ruhy.kz/news/77623-polovina-selskikh-shkol-kazakhstana-iavliaiutsia-malokomplektnymi/amp),
[Министерство просвещения РК](https://www.gov.kz/memleket/entities/edu/press/news/details/917566?lang=ru),
[The Astana Times](https://astanatimes.com/?p=111300).

**Основной сценарий.**
Учитель вводит предмет и от одного до четырёх классов с темами (у каждого свой язык обучения, класс можно выбрать дважды) → код составляет расписание на 45 минут
(учитель по очереди объясняет и проверяет каждый класс), ИИ пишет содержание урока, а код проверяет его по девяти правилам (учитель в каждую минуту не больше чем с одним классом, таймлайн без дыр,
до объяснения учителя класс только повторяет и т.д.) и при ошибке просит модель исправить урок →
учитель получает поминутный план для всех классов; для каждого класса объяснение новой темы (с чего начать,
правило, шаги, разобранный пример, типичные ошибки, вопросы классу), которое можно показать на экране слайдами;
карточки для самостоятельной работы с подсказкой без ответа и ответом для самопроверки (их хватает на всё время,
пока класс работает без учителя: код проверяет по минутам на каждую карточку); домашнее задание.
Всё можно распечатать или скопировать. Урок сохраняется со ссылкой и шестизначным кодом →
ученики входят по коду с телефона, решают карточки своего класса, получают до трёх подсказок без готового ответа
и могут позвать учителя → учитель на своей странице видит, кто на какой карточке, кто просит помощи и какие карточки
оказались трудными для класса, и ведёт урок по таймеру. Любой текст урока учитель может исправить сам.

**Телефоны в классе.** Для учебного задания телефон используется по указанию учителя: до начала учитель
объясняет задание и время работы (приказ Министра просвещения РК от 24.09.2026 № 282-НҚ,
[текст правил](https://prg.kz/document/?doc_id=37044103), действует с 9 октября 2026).
Без телефонов карточки можно распечатать.

**Форма продукта.** Веб-приложение (сайт), открывается в браузере на компьютере и телефоне, без регистрации:
https://aulsabaq-ai.vercel.app. Интерфейс и уроки на казахском и русском.

**AI-инструменты и вклад.**
- В продукте: OpenAI API пишет содержание урока (с 19 ноября модель `gpt-6.1-terra`, проверки урока и подсказки
  ученику делает быстрая `gpt-6-luna`; `docs/TEST_LOG.md`, проверка 8): объяснение темы для каждого
  класса, карточки повторения и практики с подсказками, описания этапов, домашнее задание, и вычитывает урок
  на опечатки. Ответ строго по JSON-схеме (Structured Outputs). Модели выбраны по замерам на одинаковых уроках
  (`docs/TEST_LOG.md`, проверки 5 и 8). До 18 ноября работал Google Gemini, 18–19 ноября `gpt-6-luna`; код
  поддерживает оба провайдера (переключается переменными окружения).
- Во время урока ИИ даёт ученику вторую и третью подсказку к карточке с учётом его ответа. Сервер проверяет каждую
  подсказку и отбрасывает ту, где есть ответ; если ИИ недоступен, ученик получает запасную подсказку.
- По просьбе учителя ИИ заменяет одну карточку («проще», «про хозяйство»), новая карточка проходит те же проверки.
- Что делает код без ИИ: расписание по минутам (кто с учителем, кто сам), раскладку карточек по этапам,
  проверку всего, что вернула модель (девять правил, пересчёт примеров, совпадение с запросом учителя),
  проверку ответов учеников, панель учителя и таймер урока.
- В разработке до 24 ноября основную часть кода, тестов и документации писал Claude Code (Anthropic) по заданиям автора.
- 24–25 ноября код доработок T1–T11, в том числе эксперимент T8, тесты и оформление документов выполнялись
  в Codex. Автор подтвердил работу в ChatGPT Edu, workspace «Startup Ecosystem». Это вклад в доработки,
  а не заявление, что весь проект создан в Codex. Задачи и проверки записаны в журнале `docs/PLAN.md`.
- 25 ноября Claude Code провёл контрольную проверку в браузере перед слиянием, применил миграцию
  `t7_shared_lesson_clock`, включил `RUN_SYNC=on` на Vercel в 14:54 по Астане и по разрешению автора
  слил PR #1–#12 в main (итоговый коммит `c816ff5`). Версия выложена в 14:57. Claude Code проверил

  неверный ответ и передачу просьбы о помощи учителю. Общий таймер работает; тестовые сеансы относятся

- Codex подготовил этот паспорт, шаблоны проверки с учителями, рецензий и репетиции. Отзывы, публикации и отправку
  конкурсной формы они не заменяют. Реального замера времени с учителями на 24 ноября пока нет.

**Условия запуска в workspace.**
- Проверяющему нужен только браузер и ссылка. Регистрация, подписка и личные данные не нужны.
- Сервисы автора: хостинг Vercel (бесплатный тариф Hobby), база Supabase (бесплатный тариф, Франкфурт),
  OpenAI API (оплачивает автор, ключ хранится только на сервере). Для проверяющего 0 ₸; для автора около
  9–17 центов за урок (`docs/TEST_LOG.md`, проверка 8).
- Создание урока занимает 1–2,5 минуты: объяснение каждого класса, карточки и корректура — отдельные запросы;
  урок по языку до 3 минут, потому что его дополнительно проверяет рецензент правил.
- Лимит уроков по IP сейчас выключен (включается переменной `RATE_LIMITS=on`). Всегда работает общий дневной
  предел сайта на платную модель: 150 уроков, 400 замен карточек, 5000 ИИ-подсказок в сутки. Демо-урок и его копия
  с кодом для учеников открываются без вызова модели.
- Для своего запуска: Node.js, `npm install`, ключ Gemini или OpenAI в `.env.local` (см. README).

**Данные и ограничения.**
- Данные: в модель уходят только предмет, язык, классы, темы урока и заметка учителя о классе. Их обрабатывают
  серверы Vercel и OpenAI; запросы отправляются с `store: false` (OpenAI не хранит их как разговоры). Если учитель добавил фото
  страниц учебника, они уходят в модель вместе с запросом и нигде не сохраняются. Для подсказки в модель
  уходит текст карточки и ответ ученика, без имени. Урок и прогресс учеников хранятся в Supabase (ЕС).
  Об ученике хранится только имя или номер в списке, который он сам ввёл; почты, телефона, аккаунтов и паролей нет.
  Учитель без аккаунта: доступ к правке и списку учеников даёт ключ в его браузере (в базе только его хеш).
  В логах сервера только коды ошибок и, для ошибок в счёте, сама неверная формула; текста уроков и имён там нет.
- Работает: создание урока на казахском и русском для 1–4 классов (с 19 ноября; в MVP 2–3), в том числе урок, где у классов разный язык, проверка урока по девяти правилам (в том числе
  пересчёт всех примеров вида «6 + 8 = 14») с двумя повторными попытками, повтор запроса при перегрузке модели, страница урока с таймлайном, объяснением темы, показом слайдов и карточками с подсказками, печать
  (ответ печатается вверх ногами внизу карточки), копирование текста, готовый демо-урок.
- Итоговый продукт (17 ноября) добавил: сохранение урока со ссылкой и кодом, режим ученика с проверкой ответа,
  подсказками ИИ и кнопкой «Мне нужна помощь учителя», панель учителя, таймер урока, правку урока и замену карточки;
  наглядные слайды (деление уголком, столбик, числовой луч, графики с площадью, разбор предложения, состав слова,
  схемы, таблицы; всё, что можно посчитать, считает код), три разобранных примера и «Попробуй сам»;
  необязательные фото страниц учебника; объяснение по лестнице «простой пример, как в учебнике, с подвохом,
  из жизни» с проверкой ответа, «простыми словами», новые слова и итог; число карточек считается по времени.
- После собственного аудита 19 ноября (`docs/AUDIT.md`) исправлено: в уроках по языкам работает рецензент правил;
  проверка ответа ученика засчитывает короткую запись ответа и требует все корни уравнения, а под заданием написано,
  в каком виде вписать ответ; после верного ответа ученик видит «Верно!»; наглядный блок «группы» умеет сложение
  и вычитание, а блок, который противоречит подписи, код выбрасывает; общий дневной предел расходов на модель.
- Не реализовано: аккаунты учителя (урок привязан к браузеру; на телефон переносится «Ссылкой для себя»),
  офлайн-режим, автоматическое удаление старых уроков, выставление оценок.
- Имитируется: телефон ученика на главной странице и переписка в разделе «Для учеников» — анимации,
  которые иллюстрируют настоящий режим ученика.
- Известные ограничения качества: модель иногда ошибается в формулировках и правилах (особенно в казахской
  грамматике: шырайы сын есімнің), карточки «Повторение» у старших классов иногда касаются новой темы.
  С 19 ноября уроки по языкам проверяет рецензент правил (`docs/TEST_LOG.md`, проверка 6), но и он может ошибиться,
  а казахскую грамматику ещё должен проверить носитель-методист. Поэтому на странице урока написано, что учитель
  просматривает задания перед уроком.
- Доступность: у нового аккаунта OpenAI низкие лимиты токенов в минуту; при отказе сайт ждёт столько, сколько
  просит OpenAI, и повторяет. Если урок так и не собрался, показывает понятную ошибку и предлагает демо-урок,
  который открывается всегда.

## Запуск и проверка

Инструкция для итогового продукта на 5 минут (демо-урок → код → ученик → панель учителя): `docs/REVIEWER_GUIDE.md`.
Ниже — проверка MVP, сданного 16 ноября.

- **Workspace ChatGPT Edu организации:** ChatGPT Edu — Startup Ecosystem (вход через Bilimland, MoE Kazakhstan)
- **Название опубликованного объекта:** AulSabaq AI, Асанали Аскаров
- **Сдаваемая версия и дата публикации:** ветка `main` репозитория, последний коммит на 16 ноября 2026
  (работающая версия на https://aulsabaq-ai.vercel.app, проверена 16 ноября 2026)
- **Инструкция:**
  1. Откройте https://aulsabaq-ai.vercel.app (сайт сам выберет русский или казахский; переключатель «Қаз / Рус» вверху).
  2. Нажмите «Создать урок».
  3. В поле «Предмет» выберите «Математика», язык урока «Русский», длительность оставьте 45.
  4. Группа 1: класс 2, тема «Сложение двузначных чисел с переходом через десяток».
  5. Группа 2: класс 4, тема «Деление на однозначное число».
  6. Нажмите «Собрать урок» и подождите до 1–2 минут (обычно меньше минуты).
  7. На странице урока посмотрите «Ход урока»: в каждую минуту учитель только с одним классом.
  8. Ниже в «Объяснение новой темы» нажмите «Показать на экране» и листайте слайды стрелками (пример
     открывается по шагам). Затем карточки обоих классов: метки «Повторение» и «Новая тема», «Подсказка»,
     «Показать ответ».
  9. Нажмите «Распечатать карточки» (предпросмотр печати) или «Скопировать урок».
  10. Если создание недоступно (лимит или перегрузка модели), нажмите «Открыть демо-урок» на главной.
- **Исходные тестовые данные:** Математика, русский, 45 минут; 2 класс: «Сложение двузначных чисел с переходом
  через десяток»; 4 класс: «Деление на однозначное число».
- **Действия и кнопки:** «Создать урок» → заполнить форму → «Собрать урок» → «Показать на экране»
  (стрелки, Esc) → «Подсказка» и «Показать ответ» в карточке → «Распечатать карточки» / «Скопировать урок».
- **Ожидаемый результат и признаки правильной работы:** урок создан за 2–3 минуты; предмет, классы
  и темы совпадают с введёнными; у каждого класса таймлайн непрерывно покрывает 0–45 минут; в каждую минуту
  учитель не больше чем с одним классом, начало и конец общие; у каждого класса есть объяснение темы с разобранным
  примером, а этап «с учителем» разбирает этот же пример; у каждого класса карточки с подсказкой (в MVP 5–6,
  в итоговом продукте столько, сколько нужно на время самостоятельной работы, до 30), у закрытых
  есть ответ, и подсказка его не называет; пока класс не работал с учителем, у него только карточки «Повторение»;
  есть домашнее задание.
- **Дата самостоятельной проверки и фактический результат:** три проверки по пять уроков (русский и казахский,
  2–3 класса, классы 1–9).
  - 13 ноября, проверки 1 и 2 (урок без объяснения темы): во второй 5 из 5 уроков созданы за 5–13 секунд.
  - 16 ноября, проверка 3 (с объяснением темы и слайдами): 5 из 5 уроков созданы за 35–130 секунд, все признаки
    выполнены, урок 1 дополнительно создан через форму в браузере. По пути найдены и исправлены перегрузка
    модели (добавлены запасные модели) и два ложных срабатывания проверок.
  - Найденные ошибки содержания записаны. Подробно: `docs/TEST_LOG.md`.
