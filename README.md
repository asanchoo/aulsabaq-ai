# AulSabaq AI

ИИ-помощник для учителей малокомплектных школ Казахстана: совмещённый урок для 2–3 классов за минуты,
карточки для самостоятельной работы и подсказки ученикам без готовых ответов.

Заявка на Codex Challenge (Bilim AI × OpenAI, ChatGPT Edu).

## Для проверяющего
Сайт: **https://aulsabaq-ai.vercel.app**. Нужен только браузер: без регистрации, подписки и личных данных.
Пошаговая инструкция на 5 минут: [`docs/REVIEWER_GUIDE.md`](docs/REVIEWER_GUIDE.md). Коротко:

1. «Открыть демо-урок» → «Получить код для учеников»: своя копия урока с шестизначным кодом.
2. На телефоне или во второй вкладке: `aulsabaq-ai.vercel.app/join` → код → «4 класс» → имя.
3. Неверный ответ, «Подсказка» (без готового ответа), «Мне нужна помощь учителя», верный ответ.
4. На вкладке урока в «Ученики на уроке» видно, кто на какой карточке, кто просит помощи и где классу трудно.
5. Свой урок: «Создать урок», два класса с темами, «Собрать урок» (обычно 1–2 минуты, урок по языку до 3 минут, ИИ).

Паспорт проекта: [`docs/PROJECT_PASSPORT.md`](docs/PROJECT_PASSPORT.md). Записи проверок: [`docs/TEST_LOG.md`](docs/TEST_LOG.md).

**Что умеет:** урок для 2–3 классов по минутам; объяснение темы слайдами со схемами (деление уголком, столбик,
числовой луч, графики, разбор предложения, состав слова, таблицы) и тремя разобранными примерами; по желанию
по фото страниц своего учебника; карточки с подсказками, которых хватает на всё время самостоятельной работы
(код проверяет по минутам на каждую карточку), печать;
урок сохраняется со ссылкой и кодом; режим ученика с проверкой ответа (у карточки написано, в каком виде вписать
ответ) и подсказками ИИ без ответа; в уроках по языкам отдельный проход «рецензент правил» ищет ошибки в правилах;
панель учителя с флагом «нужна помощь»; таймер «Начать урок»; правка любого текста и замена одной карточки через ИИ.
**Чего нет:** аккаунтов (урок привязан к браузеру учителя, на другое устройство переносится «Ссылкой для себя»),
офлайн-режима, оценок в журнал. Урок составляет ИИ, поэтому учитель просматривает карточки перед уроком.

## Зависимости, лицензии и расходы
- Next.js, React, Tailwind CSS, Zod, Vitest: лицензия MIT. Шрифты Manrope и JetBrains Mono: SIL OFL 1.1.
- Хостинг Vercel (тариф Hobby, бесплатно). База Supabase (бесплатный тариф, Франкфурт).
  Модель: OpenAI `gpt-6-luna` (около 1–2 центов за урок, платит автор); можно переключить на Gemini.
- Расходы для проверяющего: 0 ₸. Ключ модели хранится только на сервере, в репозитории его нет.

## Создание урока
Откройте `/ru/teacher/new` или `/kk/teacher/new`. Для живой генерации нужен один провайдер модели:

| Провайдер | Переменные в `.env.local` (или в Vercel) |
|---|---|
| OpenAI | `OPENAI_API_KEY`, `OPENAI_MODEL` |
| Gemini | `GEMINI_API_KEY` (из Google AI Studio), `GEMINI_MODEL` |

`AI_PROVIDER=openai|gemini` выбирает провайдера явно. Если он не задан, используется тот, у кого заполнены
ключ и модель; если заполнены оба, OpenAI. После изменения перезапустите приложение (на Vercel: Redeploy).
Ключи используются только сервером. Модель должна поддерживать JSON-ответ по схеме
(Structured Outputs у OpenAI, `responseJsonSchema` у Gemini).

`DEMO_MODE=true` позволяет проверить всю цепочку без платного запроса: форма → API → страница результата.
При этом результат — готовый русский демо-урок, а не урок по введённым темам; интерфейс показывает это явно.
Кнопка «Демо-урок» всегда доступна без ключа независимо от `DEMO_MODE`.

## База (Supabase)
Уроки, сессии учеников и счётчики лимитов хранятся в Supabase. Схема с комментариями: `supabase/schema.sql`
(выполнить один раз в SQL Editor нового проекта). В `.env.local` и в Vercel нужны `SUPABASE_URL` и `SUPABASE_KEY`
(публичный ключ `sb_publishable_…`): таблицы закрыты, сервер вызывает только функции базы, которые сами проверяют
ключ учителя. Без этих переменных сайт работает как раньше: урок живёт в текущей вкладке, без кода для учеников.

Лимиты на IP (общие для всех экземпляров сервера): 10 уроков, 30 замен карточек, 400 подсказок в час.
Подсказок много, потому что весь класс сельской школы выходит в интернет через один IP. Сейчас лимиты на IP
выключены по решению автора (тестирование с учителями из одной школы), включаются переменной `RATE_LIMITS=on`.
Всегда работает общий дневной предел сайта на платную модель: 150 уроков, 400 замен карточек и 5000 ИИ-подсказок
в сутки (`DAILY_LESSON_CAP`, `DAILY_CARD_CAP`, `DAILY_HINT_CAP`). Когда предел ИИ-подсказок исчерпан, ученик
получает запасную подсказку, демо-урок открывается всегда.

Как устроено: `lib/providers.ts` отправляет запрос нужному провайдеру и достаёт текст ответа,
Расписание по минутам считает код (`lib/schedule.ts`), а `lib/ai.ts` сначала параллельно запрашивает у модели объяснение темы для каждого класса, потом содержание урока (карточки, этапы, домашнее задание), проверяет каждый ответ (Zod → инварианты и пересчёт примеров → совпадение с запросом) и при ошибке делает до двух повторных попыток.
В уроках по языкам после этого отдельный запрос с размышлением `medium` проверяет правила (`lib/rules.ts`): код подсказывает ему словарные слова и корни с чередованием рядом со словом «проверочное», а исправление применяет, только если оно проходит все прежние проверки и не приносит нового подозрительного слова. Последний шаг — корректура опечаток.
Документация: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs),
[Gemini generateContent](https://aistudio.google.com/api-reference/generate-content).
