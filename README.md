# AulSabaq AI

ИИ-помощник для учителей малокомплектных школ Казахстана: совмещённый урок для 2–3 классов за минуты,
карточки для самостоятельной работы и подсказки ученикам без готовых ответов.

Заявка на Codex Challenge (Bilim AI × OpenAI, ChatGPT Edu).

## Для проверяющего
Сайт: **https://aulsabaq-ai.vercel.app**. Нужен только браузер: без регистрации, подписки и личных данных.

1. Откройте сайт и нажмите «Создать урок».
2. Предмет «Математика», язык «Русский», 45 минут.
3. Группа 1: 2 класс, «Сложение двузначных чисел с переходом через десяток». Группа 2: 4 класс, «Деление на однозначное число».
4. Нажмите «Собрать урок» и подождите 5–20 секунд.
5. Проверьте: в «Ходе урока» учитель в каждую минуту только с одним классом; в «Объяснении новой темы»
   у каждого класса правило, шаги, разобранный пример и вопросы, «Показать на экране» листает их слайдами;
   у каждого класса 5–6 карточек с подсказкой и ответом; пока класс не работал с учителем, у него только
   карточки «Повторение».
6. Если создание недоступно (лимит 10 уроков в час или перегрузка модели), откройте «Демо-урок».

Паспорт проекта: [`docs/PROJECT_PASSPORT.md`](docs/PROJECT_PASSPORT.md). Записи проверок: [`docs/TEST_LOG.md`](docs/TEST_LOG.md).

**Что пока не сделано:** режим ученика с подсказками ИИ (следующий этап, на сайте помечен «скоро»),
сохранение урока и общая ссылка (урок живёт в текущей вкладке). Урок составляет ИИ, поэтому учитель
просматривает карточки перед уроком.

## Зависимости, лицензии и расходы
- Next.js, React, Tailwind CSS, Zod, Vitest: лицензия MIT. Шрифты Manrope и JetBrains Mono: SIL OFL 1.1.
- Хостинг Vercel (тариф Hobby, бесплатно). Модель: Google Gemini API, бесплатный тариф; можно переключить на OpenAI.
- Расходы для проверяющего: 0 ₸. Ключ модели хранится только на сервере, в репозитории его нет.

## Создание урока
Откройте `/ru/teacher/new` или `/kk/teacher/new`. Для живой генерации нужен один провайдер модели:

| Провайдер | Переменные в `.env.local` (или в Vercel) |
|---|---|
| OpenAI | `OPENAI_API_KEY`, `OPENAI_MODEL` |
| Gemini | `GEMINI_API_KEY` (из Google AI Studio), `GEMINI_MODEL` |

`AI_PROVIDER=openai|gemini` выбирает провайдера явно. Если он не задан, используется тот, у кого заполнены
ключ и модель; если заполнены оба, OpenAI. После изменения перезапустите приложение (на Vercel: Redeploy).
Ключи используются только сервером. Модель должна поддерживать JSON-ответ по схеме
(Structured Outputs у OpenAI, `responseJsonSchema` у Gemini).

`DEMO_MODE=true` позволяет проверить всю цепочку без платного запроса: форма → API → страница результата.
При этом результат — готовый русский демо-урок, а не урок по введённым темам; интерфейс показывает это явно.
Кнопка «Демо-урок» всегда доступна без ключа независимо от `DEMO_MODE`.

До подключения Supabase результат живёт только в текущей вкладке браузера; доступны печать и копирование.
Лимит генерации — 10 запросов в час на IP в Vercel, вне Vercel общий лимит на процесс.
Счётчик пока в памяти: перед масштабированием необходимо подключить общее хранилище лимитов.

Как устроено: `lib/providers.ts` отправляет запрос нужному провайдеру и достаёт текст ответа,
`lib/ai.ts` параллельно запрашивает расписание с карточками и объяснение темы для каждого класса, проверяет каждый ответ (Zod → инварианты и пересчёт примеров → совпадение с запросом) и при ошибке делает до двух повторных попыток.
Документация: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs),
[Gemini generateContent](https://aistudio.google.com/api-reference/generate-content).
