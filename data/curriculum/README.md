# База типовых учебных программ

Все 128 типовых программ из приказа министра просвещения РК от 16.09.2022 № 399 (рег. № 29767) с изменениями:
все предметы, 1–11 классы, на русском и казахском. Источник:
[zakon.uchet.kz, ru](https://zakon.uchet.kz/rus/docs/V2200029767), [kk](https://zakon.uchet.kz/kaz/docs/V2200029767).

Программы утверждены приказом, это официальный документ: по ст. 8 закона «Об авторском праве и смежных правах»
он не охраняется авторским правом, поэтому его можно хранить и использовать в продукте. Учебники в базу не входят.

## Что внутри

- `index.json`: список программ с числом целей, четвертями плана и замечаниями.
- `programs/<id>.json`: одна программа. Например, `matematika-1-4.json`.

```text
id           matematika-1-4
subject      { ru: "Математика", kk: "Математика" }
grades       [1, 2, 3, 4]
variant      язык обучения, направление 10–11 классов, сетевые школы
hours        { "2": { week: 4, year: 136 } }
content      базовое содержание по классам, ru и kk
goals        { "2.1.1.2": { grade: 2, ru: "читать, записывать и сравнивать двузначные числа",
                            kk: "...", section: "Числа и величины", subsection: "Натуральные числа и число 0. Дроби" } }
plan         { "2": [ { quarter: 1, ru: ["1. Все обо мне ...", "1А Двузначные числа", ...], goals: ["2.1.1.1", ...] } ] }
warnings     опечатки приказа, которые не вошли в базу
source       откуда взято
```

Код цели: класс.раздел.подраздел.номер (`2.1.1.2`). Часть программ (языки, история, геометрия 10–11)
пишет короче: класс.раздел.номер (`10.1.1`).

## Цифры (25 ноября 2026)

- 128 программ, 11 220 целей, у 10 759 есть казахский текст.
- 14 программ без кодов целей (букварь и әліппе 1 класса, курсы «Глобальные компетенции», краеведение и др.):
  у них в приказе нет кодированных целей, есть только содержание.
- Казахский текст не найден для части программ с таджикским языком обучения, информатики 5–9 и географии 10–11.
- 18 замечаний: опечатки в кодах в самом приказе (например, `10.4.9.1` в программе 5–9 классов). В базу не вошли,
  перечислены в `warnings` программы.

## Как пересобрать

```bash
python3 scripts/curriculum/build.py
```

Скрипт скачивает приказ в `.cache/curriculum/` (не в git), разбирает его за пару секунд и перезаписывает эту папку.
После пересборки запустить `npm test`: `tests/curriculum.test.ts` проверяет, что цели не потерялись,
коды относятся к классам программы, а у математики 1–4 есть план на все четыре четверти.

Весь приказ на двух языках весит 38 МБ HTML, база 12 МБ. Для одного урока нужна одна программа
(в среднем около 100 КБ), а модели отдаются только цели нужного класса и четверти: несколько килобайт.
